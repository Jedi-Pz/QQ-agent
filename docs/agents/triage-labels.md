# Triage 标签

各 skill 内部使用五个标准的 triage 角色名。本文件把角色名映射到本仓库 issue tracker 中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库使用的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 描述完整，可以交给离线 agent 处理 |
| `ready-for-human` | `ready-for-human` | 必须由人来实现 |
| `wontfix` | `wontfix` | 不予处理 |

当某个 skill 提到某个角色（例如「打上 AFK-ready 的 triage 标签」）时，使用上表右列对应的标签字符串。

如果你的仓库实际用的不是这套词，改右列即可。
